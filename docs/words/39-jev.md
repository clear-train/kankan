# Jev 与决策模型

## 一句话

它不回答「怎么说」，只回答「选哪个、打几分、真不真」，答完直接进代码。

## 饭桌上可以这么说

- **同事局**：「它是那个不写报告、只举手的人。你问它二十遍该点哪儿，它每次给一个数，还带概率。」
- **老板局**：「它把『要不要转人工』这类判断从聊天里拆出来，变成一行能审计的代码，省的是延迟和账单。」
- **亲戚局**：「像快递站的分拣工。不跟客户聊天，一秒钟分完一件，格式从来不出错。」

## 它到底怎么转的

先给它一段状态——工单内容、网页上可点的元素、候选动作；再给它几道有类型的题：Choice 从固定选项里挑一个，Score 按标准打分，Noul 判断一句话真假（[官方介绍](https://thejevai.com/zh/blog/jev-ai-introduction)）。它输出的不是文字，是结构化结果加概率。

技术上最要紧的一步是跳过逐字生成。普通模型要一个词一个词写，写完再校验格式；它一次前向计算，直接给每道题打分。省的不只是时间，还有那类「格式写错了再重试」的麻烦——这种错在 Agent 里最贵，因为你不知道它刚才点错了哪个按钮。

TypeSafe 自己的口径是：分类决策上比前沿大模型快近两百倍，成本低到约四百分之一（[央广网报道](https://tech.cnr.cn/techph/20260920/t20260920_527819594.shtml)）。这是官方自测，不是第三方评测，听的时候要打折。

## 说到这儿就该停了

- **错**：「它是更快的 LLM。」——它连文本都不生成，答案空间是你提前定义好的。
- **错**：「输出里的概率就是准确率。」——那是模型内部的信心，不是历史胜率，得自己拿样本量。
- **错**：「让 LLM 输出 JSON 就够了。」——那是先写完再校验，慢，而且会漂；决策模型把校验挪到了接口的形状上。
- **追问「那大模型是不是没用了？」**——「规划、解释、开放式推理还归它。这套分工叫快慢分工：慢思考留给大模型，高频小判断交给决策模型。」

## 这个词是怎么被用坏的

「决策模型」现在一半是技术，一半是货架标签。2026 年下半年起，[模型市场](https://thejevai.com/)上挂出了一串带 clef、decider、decide 后缀的型号，谁都能说自己是决策层。真正的分界只有一条：**你的答案空间能不能提前写死**。写不死，它就是又一个贵一点的分类器。

名字取自杰文斯，因为「智能变便宜，用量就暴涨」——这条悖论我们[单独写过](/words/38-jevons)。讽刺的地方在这儿：它省下的成本，确实没让人少用，只是让人开始拿它去判那些以前懒得判的小事。
