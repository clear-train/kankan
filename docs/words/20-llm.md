# 大模型（LLM）

## 一句话

一个把「接下来最可能出现的词」算了千百亿次的东西。

## 饭桌上可以这么说

- **同事局**：「它本质是个概率机器。它不查答案，它接话。接得准的时候，我们叫它智能。」
- **老板局**：「它不是数据库，是个实习生：见过很多，记性一般，态度很好，偶尔瞎编。」
- **亲戚局**：「像个读过很多书的复读机。但读得实在太多了，所以偶尔真能说出点东西。」

## 它到底怎么转的

文字进来，切成 token，每个 token 变成一串数字，穿过几十层网络，最后输出「下一个 token 是每个候选词的概率」。

挑一个接上去，再算下一个。所谓「生成」，就是这个循环重复几百次。

为什么它看起来像懂？因为「猜下一个词」这个任务太苛刻了。要猜得准，模型必须把语法、事实、逻辑、语气统统压缩进参数里。它没被教过逻辑，但为了猜准，它不得不学一点。

## 说到这儿就该停了

- **错**：「参数越多越聪明。」——参数是容量，不是智力。还得看喂了什么、怎么训的、有没有被调教过。
- **错**：「它在思考。」——它在采样。思考是你的解读，也是产品文案的解读。
- **追问「它为什么答错了？」** ——「它在补全一个看起来合理的答案，不是在检索。合理和正确，大部分时候重合，偶尔分家。」

## 这个词是怎么被用坏的

「大模型」三个字，已经从技术名词变成了万能前缀：大模型手机、大模型冰箱、大模型马桶。它们大多只是接了个 API，但「大」字必须留着，因为「大」是这个时代最便宜的说服力。

更微妙的是，这个词让「模型」听起来像个成品。其实它更像个半成品：一个读过很多东西、但没有常识、没有记性、也没有责任心的东西。我们给它起名叫「大模型」，它自己大概不会同意。
