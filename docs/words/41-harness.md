# Harness（脚手架）

## 一句话

Agent 的本事有一截不在模型里，在模型外面那层壳上。

## 饭桌上可以这么说

- **同事局**：「同一个模型，换个壳，跑分能差出一截。模型是发动机，壳是变速箱。」
- **老板局**：「买模型只是买发动机。方向盘、刹车、仪表盘得自己装，装不好照样开沟里。」
- **亲戚局**：「像请了个聪明的实习生，没给他配电脑和门禁。本事再大，也进不了门。」

## 它到底怎么转的

模型只会一步：给一段话，接下一段。可 Agent 要干的活常常是二十步，中间得有人替它转：把工具清单翻译成它能读的格式，把它想调的工具真调出去，把结果塞回去再问下一轮。失败重试几次、什么时候放弃、上下文满了删哪段、钱花到哪停，这些都不在模型权重里。这层包在外面的工程，行业里叫 Harness（[央广网报道](https://tech.cnr.cn/techph/20260920/t20260920_527819594.shtml)）。

同一个模型，换个壳，结果能差一截。工具说明写得含糊，它就乱调；重试不设上限，一次超时能变成一个下午的账单；没有状态存档，第三步崩了从头再来。这些改动不碰一个参数，榜单名次能挪。

壳也有它管不到的地方。模型答不对的题，壳修不出来；壳能做的，是别让它把短板露在关键那一步。发动机不行，变速箱再好也跑不快；变速箱不行，发动机再好也上不了路。

## 说到这儿就该停了

- **错**：「Agent 就是模型加插件。」——插件是能力，壳是流程。流程不对，插件越多越乱。
- **错**：「壳是胶水，谁都能写。」——胶水决定漏不漏。工具循环、状态、重试、预算，每一样都能把任务做死。
- **错**：「换个更强的模型，Agent 就好了。」——模型换了，壳里的老毛病原封不动搬过去，只是错得更快、更贵。
- **追问「那壳和模型，哪个更值得投？」**——「看瓶颈在哪。模型答不对，投模型；模型答得对但事没做成，投壳。多数团队卡在后者，却一直在换前者。」

## 这个词是怎么被用坏的

发布会讲模型，工程里全是脚手架。大家记的是参数量和榜单，没人给变速箱开发布会。「换模型没用，换脚手架才有用」这句话，一半团队说出来是经验，另一半是给自己的壳找台阶：换壳是自己动手，换模型是等别人发货。判断标准很土：把壳拆了重装一遍，任务成功率动不动。不动，问题就不在这层。
