# MoE、蒸馏与量化：把模型塞进口袋

## 一句话

模型能塞进口袋，是有人在三个地方各砍了一刀。

## 饭桌上可以这么说

- **技术局**：「MoE 像医院分科室：楼盖得很大，你挂一次号只惊动一个科。」
- **老板局**：「同一件事有三种省钱法，宣传册只印省下来的那部分。」
- **亲戚局**：「好比把整套家当搬进小房子，能住，就是转身得小心。」

## 它到底怎么转的

MoE 是「专家混合」：模型里养着很多组子网络，每来一个词，只挑其中一两组干活。总容量很大，单次计算量不大。像医院楼大、科室全，但你一次只看一个科。

蒸馏是让小学生抄思路。先拿大模型对海量问题生成回答，再让小模型去学这些回答的分布。学生学的是老师怎么一步步想，不是把答案背下来。

量化是换刻度。参数原本用高精度小数存，改成低精度整数，常见是从 16 位压到 8 位甚至 4 位。显存省了，速度也快，代价是数值变粗，少数任务会掉点。

## 说到这儿就该停了

- **错**：「MoE 是很多小模型投票。」——不是投票。每算一个词，按 token 挑几个专家，最后合成一个输出。
- **错**：「蒸馏就是把大模型复制一份。」——复制要同样的参数和算力。蒸馏只搬行为，学生比老师小得多。
- **错**：「量化无损。」——一定有损，只是很多任务上看不出来。
- **追问「那到底能省多少？」** ——「三种都是拿一点能力换成本。省多少、掉多少，得看具体任务，宣传页一般不写后半句。」

## 这个词是怎么被用坏的

「压缩」出现在发布会上时，后面跟着「同等性能、成本下降」；出现在论文里时，后面跟着一张掉点的表。两个说法都不算撒谎，只是取景框不同。久而久之，「小模型够用了」变成一句信仰——它可能是真的，也可能只是这一季的预算。
