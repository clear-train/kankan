# 推理模型与思维链

## 一句话

它没变聪明，只是被逼着把草稿写出来了——而写下来，确实更容易算对。

## 饭桌上可以这么说

- **同事局**：「思维链是让它打草稿，推理模型是把打草稿练成习惯。一个靠提示，一个靠训练。」
- **老板局**：「难题上多想一会儿确实更准，账单也更准。简单问题用它，是叫专车去买一瓶酱油。」
- **亲戚局**：「像考试时先在草稿纸上算。草稿纸有用，但他那张草稿，可能是编的。」

## 它到底怎么转的

它一次只吐一个 token，没有隐藏的「思考」步骤。所谓推理，是把中间过程也当成要写的字写出来。草稿和答案一样，都是采样。

为什么写出来会变准？因为下一步只能看前面的字。把中间结果落到纸上，等于给自己造了一段可以回看的上下文。**它不是在脑子里算，是在纸上算。** 人也一样，心算两位数乘法容易错，写下来就对得多。

推理模型是把这件事训成默认动作：用强化学习一类方法，奖励最终算对的路径，让它自己学会先展开、再收敛。多给算力让它多想，难题正确率确实上去，这叫测试时计算。代价是错的中间步骤，它也能一路写得很顺。

## 说到这儿就该停了

- **错**：「它在做逻辑推演。」——它在生成一段看起来像推演的文本。这段文本恰好帮它算对了，机制仍是接话，只是接得长。
- **错**：「思维链越长越准。」——方向跑偏的草稿，越长错得越远，而且每一步都显得有理有据。
- **错**：「推理模型不会错在简单题上。」——它会把一道小学题想很久，然后错在第一步。
- **追问「那它到底会不会推理？」**——「需要推理的题它做对了不少。它和你是不是同一种推理，我们没有判据，而且这件事，问它自己是问不出来的。」

## 这个词是怎么被用坏的

「推理」现在成了界面用语：转圈叫推理，多等三秒叫深度思考，出错叫推理链中断。

真正的区别只有一个：有没有花额外算力去展开中间步骤，以及这些步骤有没有被专门训练过。其余是等待动画。动画做得越像思考，越容易让人相信它在思考，也越难解释为什么问一句「今天几号」要等八秒，而账单按 token 算。
