# 端侧模型

## 一句话

不是把大模型塞进手机，是把问题改小到手机装得下。

## 饭桌上可以这么说

- **同事局**：「量化把参数压细，蒸馏让小模型学大模型的答案。都不让它变强，只让它变便宜。」
- **老板局**：「卖点不是参数，是延迟和数据不出这台机器。前者省时间，后者省流程。」
- **亲戚局**：「像把整套厨房换成一口锅。能做熟，做不了席。」

## 它到底怎么转的

端侧不是缩小的云端，是另一道题：同一个模型，要装进一个没有显卡、跑久了还发烫的盒子。三条路。量化，把每个参数的精度降下来。蒸馏，让小的照着大的答案练。再狠一点，砍掉用不上的能力，只留一个小领域。

三条路都换走了东西。量化换走精度，蒸馏换走上限，砍能力换走通用性。所以端侧的真实卖点从来不是「和大模型一样强」，是「不用等网络」和「数据不出这台机器」。

前一条是体验，后一条是账。一份不能出内网的材料，走云端要过审批、要签字、要排期；走本地，成本是一台设备的钱。这台设备答得笨一点，但流程当天能跑完。

## 说到这儿就该停了

- **错**：「端侧模型就是小号的大模型。」——它是被改造过的模型：精度更低、能力更窄。换来的只是不联网也能用。
- **错**：「本地运行就等于安全。」——数据不出机器，但模型和它调的工具仍然可能把内容发出去。装在本机，不等于关在屋里。
- **错**：「端侧迟早全面取代云端。」——延迟和隐私能本地解决，知识面和推理深度不能。要背下整个行业的时候，还是得连回去。
- **被追问时怎么接**：「先问它答不上来的时候怎么办。能退回云端，那叫端侧；答不上来就编，那叫演示。」

## 这个词是怎么被用坏的

宣传图上是这样的：一台手机，一个对话框，一句刚好答得上的问题。参数不写，模型不写，只写「本地运行」。

它确实在本地跑了，跑的是一个压过精度、砍过能力的版本，和发布会上那个不是一个东西。

端侧真正难的不是把它装进去，是承认装进去以后它变了。
