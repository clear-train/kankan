# RAG（检索增强生成）

## 一句话

RAG 是开卷考试：书就在旁边，翻错页照样答错，还答得更理直气壮。

## 饭桌上可以这么说

- **同事局**：「它没变聪明，是允许翻书了。翻得准不准，全看前半段那个检索。」
- **老板局**：「私有资料、时效、瞎编，它能救一部分。救不救得回来，看找得准，不看模型大小。」
- **亲戚局**：「像开卷考试。书摊在旁边，他翻错页，照样写满一整页，还挺有底气。」

## 它到底怎么转的

先把文档切成小段，每段变成一串数字，存进库里。这串数字叫向量，代表意思：意思近的，数字也近。切法很要命——切碎了，一句话被劈成两半；切大了，一段里塞着五个主题。

你提问时，问题也变成一串数字，去库里找最近的几段，把原文拼进提示词，跟它说：照着这些回答。它能引用，是因为那几页真的摊在它眼前，不是它背下来的。

于是它治三件事：有据可依、资料能换、私有文档能读。但难点全在前半段——找得准不准。找错了，后半段越流畅，错得越体面。

## 说到这儿就该停了

- **错**：「接了 RAG 就不会幻觉。」——材料里没有答案，它照样编。区别是这次它带着引用编，你更容易信。
- **错**：「RAG 让模型学会了新知识。」——它没学。它只是每次临时摊开几页纸，合上就忘。关掉检索，它还是原来那个它。
- **错**：「向量检索懂语义，所以一定准。」——相似不等于相关。「苹果发布会」和「苹果多少钱一斤」在向量空间里可能挨得很近。
- **追问「那 RAG 最难的是哪一步？」**——「不是生成，是找。找对了，生成是顺水推舟；找错了，生成是雪上加霜，而且写得比谁都自信。」

## 这个词是怎么被用坏的

RAG 在中文里被叫成「知识库问答」，于是它成了一个产品名：把文档传上去，你就有个懂业务的 AI。真实情况是，它把一半的难题从「模型会不会说」挪到了「资料找不找得到」。

后者是搜索问题，是老问题，只是换了个新名字卖。卖方案的人通常不提这一半，因为提了就不太像 AI 了。于是「我们做了 RAG」这句话，通常等于「我们接了一个向量库」。
