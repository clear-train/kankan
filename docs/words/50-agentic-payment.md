# 代理支付

## 一句话

不是 AI 替你点确认，是你先把一笔额度交给它，事后才看它买了什么。

## 饭桌上可以这么说

- **同事局**：「现在这些『AI 付款』，多数只是替你按一下确认键，离替你做决定还差一份授权书。」
- **老板局**：「入口从收银台搬进了对话框，所以抢的不是按钮，是谁来签字。」
- **亲戚局**：「跟给孩子一张限额副卡差不多，区别是这孩子不会半夜自己下单，还会编。」

## 它到底怎么转的

拆开是四层，缺一层就出事。

**身份。** 智能体没有身份证，也没有信用分。系统得把它映射回一个真人或企业，叫 KYA，了解你的智能体。这层没有通用解法，多数靠「它用的是你的卡」来兜。

**授权。** 常见三种：额度（给一千块，花完就停）、白名单（只许在这几家买）、时间窗（只在本次会话有效）。今年六月，蚂蚁上了 AI 版支付宝「阿宝」，微信支付给智能体开了张「AI 专属卡」，与主账户隔离（[上海证券报，2026-06-24](https://paper.cnstock.com/html/2026-06/24/content_2234727.htm)）。十一月 OpenAI 给 ChatGPT 智能体发了卡片钱包，美国 Pro 用户授权运通、万事达、Visa 后可由它付款，商户不用改结账系统（[The Defiant，转自 ChainCatcher](https://www.chaincatcher.com/article/2304603)）。

**轨道。** 一条是卡组织的老路：把卡令牌化，给它一张能花但看不见卡号的凭证。另一条是稳定币：Rain 十一月出的 Agent Vaults，允许智能体在限额、指定商户、指定时间窗内付款或转账（[ChainCatcher，2026-11-11](https://www.chaincatcher.com/article/2303782)）。PayPal 加入了 x402 基金会，那套协议借 HTTP 402 状态码，把机器对机器的付款变成一次请求（[Foresight News](https://foresightnews.pro/news/detail/117421)）。

**留痕。** 出纠纷谁举证：商户说货发了，模型厂商说提示词是你写的，你说你没让它买。协议定不了这件事。

## 说到这儿就该停了

- **错**：「代理支付就是免密支付。」——免密省的是验证，代理支付多出来的是「谁授权、授权到哪一步、能不能撤销」。
- **错**：「智能体会自己决定买什么。」——多数方案仍要人确认或在额度内授权，真正的机器对机器交易还没成主流。
- **错**：「协议定了就安全。」——协议解决接口，不解决幻觉触发异常下单，也不解决多家共用一套模型的同质化风险。
- **追问「出了事谁负责？」**——「看三件事：谁授权的、谁签的字、谁留了痕。答不全，就别让它碰钱。」

## 这个词是怎么被用坏的

第一种，把「在对话框里点一下付款」叫 AI 支付。那只是收银台换了个位置，钱还是你按的。

第二种，把预测当规模。万亿是曲线，不是流水。

第三种最省事：把「智能体之间自动交易」说成已经发生。它更像一张抢着签的协议——谁把规则写成默认，谁收下一代的手续费。
