# Agent（智能体）

## 一句话

聊天机器人给你答案，Agent 替你动手——包括动错手，而且它不觉得错了。

## 饭桌上可以这么说

- **同事局**：「模型、工具、循环。想一步、做一步、看结果、再想。哪一步没有反馈，它就开始编着走。」
- **老板局**：「自主性分等级。写草稿给你审，和直接改生产库，中间差的不是技术，是责任。」
- **亲戚局**：「像刚来的实习生，手脚快、敢下手、不请示。你最好站旁边看着，还得替他签字。」

## 它到底怎么转的

聊天是一问一答，说完就完。Agent 是个循环：模型说「我要调这个工具、传这几个参数」，外面的程序真去执行，结果塞回上下文，它再决定下一步。

所以它的上限由工具决定，下限也由工具决定。工具切得细，它做得准；只给它一个「执行命令」，它也会很自信地敲下去。**它的胆子，是接口给的。**

失败方式也很特别：不是卡住，是自信地做错，而且停不下来。每一步它都觉得合理，因为每一步都是按「最可能的下一步」生成的。终止条件写歪了，它能绕一整晚，天亮时给你一份格式完美的错误报告。

## 说到这儿就该停了

- **错**：「Agent 就是更聪明的聊天机器人。」——关键差别不是聪明，是它能动手。会动手的东西，评价标准从「说得对不对」变成「赔不赔得起」。
- **错**：「全自动 Agent 明年就能用。」——这句话每年都说一次，而且每次说的都是明年。自主性越高，错误越贵，这是结构问题，不是版本问题。
- **追问「它能替我干活了吗？」**——「能替你干那种干错了你一眼看得出来的活。动钱、发邮件、改数据库，现在还得有人守着——那个人还是你。」

## 这个词是怎么被用坏的

「Agent 元年」这句话，每年都有人宣布一次，而且每次宣布的都是同一年。

后来标准一路放宽：有循环的叫 Agent，接了工具的叫 Agent，能自动补全一段话的也叫 Agent。词一旦宽到能装下所有东西，它就不再说任何事。

真正的分界线其实很土：它能不能在你不在的时候，把事情做坏。
