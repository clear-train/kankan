# Agent（智能体）

## 一句话

聊天机器人给你答案，Agent 替你动手——包括动错手。

## 饭桌上可以这么说

- **同事局**：「模型加工具加循环。想一步、做一步、看结果、再想。中间哪一步没有反馈，它就开始瞎走。」
- **老板局**：「自主性分等级。写个草稿给你审，和直接改生产环境，中间隔着好几级信任。」
- **亲戚局**：「像刚来的实习生，手脚麻利，也敢下手。你最好站旁边看着。」

## 它到底怎么转的

聊天是一问一答，一轮结束。Agent 是个循环：模型输出一个动作，比如调哪个工具、传什么参数；外部程序执行；结果被塞回上下文；模型再决定下一步。

所以它的上限很大程度由工具决定。工具切得细，它做得准；工具只给一个「执行命令」，它就会很自信地敲下去。**它的胆子，是接口给的。**

失败模式也很特别：不是卡住，是自信地做错，并且停不下来。它每一步都觉得自己合理，因为每一步都是按最可能的下一步生成的。终止条件写歪了，它能绕一整晚。

## 说到这儿就该停了

- **错**：「Agent 就是更聪明的聊天机器人。」——聪明不是关键差别。能执行、有反馈、会循环，才是。
- **错**：「全自动 Agent 很快就能用。」——这个句式每年都说一次。自主性越高，出错的代价越大，这是结构问题。
- **追问「那它能替我干活了吗？」** ——「能替你干那种错了也看得出来的活。动钱、发邮件、改数据库，现在还得有人守着。」

## 这个词是怎么被用坏的

「Agent 元年」这句话，每年都有人宣布一次，而且每次宣布的都是同一年。后来标准一路放宽：有循环的叫 Agent，接了工具的叫 Agent，能自动补全一段话的也叫 Agent。词一宽，就没有信息量了。
