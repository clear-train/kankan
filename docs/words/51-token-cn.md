# 词元

## 一句话

「词元」不是翻译，是给 token 上一个能写进标准、教材和账单的中文名。

## 饭桌上可以这么说

- **同事局**：「官方定名是词元，但它不等于词——一个汉字经常要一个多，账按它算。」
- **老板局**：「有了中文名，它才能进预算表。名字是记账的前提，不是文化工程。」
- **亲戚局**：「洋名 token，中文叫词元，像把 Wi-Fi 叫成无线保真：念着拗口，合同上得有。」

## 它到底怎么转的

2026 年 3 月 25 日，全国科学技术名词审定委员会发公告：责成第四届计算机科学技术名词审定委员会启动「科技新词快速审定」，开了几轮会，优先推荐「词元」作为 token 的中文名，发布试用（[公告原文](http://cnterm.cn/news/tzgg/202603/t20260325_827999.html)）。这家机构 1985 年受权成立，审定的名词对科研、教学、出版有约束力。

注意两个措辞：「优先推荐」「发布试用」。最终定名要等常态化审定结合应用情况确认。媒体多写「官方定了」，比原文硬。

那为什么非要一个中文名？三件事。

一要能被引用。标准、教材、公文里写 token，句子就断了；写词元，能接着写下去。

二要能被念出来。它已经进了账单和发布会，一个只能念英文的单位，在大众语境里永远是外来词。

三要能被管理。有名字才有科目，有科目才有预算线——跟[账单那篇](/industry/49-cost-visibility)是同一个机制。

定名之前有十几家译法：令牌、标记、代币、语元、词符、分词单元，各自都对一半。

## 说到这儿就该停了

- **错**：「词元就是词。」——一个汉字常被切成一个以上，一个长英文词也可能切成几段。它是最小处理单位，不是语言学上的词。
- **错**：「官方已定死，不能改。」——公告写的是试用。试用这两个字，就是留给用的人改的。
- **错**：「定中文名说明我们落后。」——恰好相反：一个概念到了要定名，说明它已经离开实验室，进了钱和流程。
- **追问「那用哪个？」**——「正式文本用词元，技术文档保留 token 并在首次出现时括注。两个一起用，比争一个正确省事。」

## 这个词是怎么被用坏的

最典型的坏用法，是把词元当字来算钱：说一千词元等于一千字，然后把中外价目表并排比。中文一个字往往一到两个词元，英文一个词三四个，跨语言报价从来不按字对齐。

第二层坏在「精确感」。名字越整齐，越容易让人以为它划的边界是技术给定的，其实那是审定会议定的。名字是协议，不是物理定律。

好在这次有个诚实的地方：公告用的是「试用」。术语和人一样，先上岗，再考核。
