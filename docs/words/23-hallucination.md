# 幻觉

## 一句话

幻觉不是它坏了，是它太顺了——它没有「我不知道」这个选项，只有「哪句话接得更自然」。

## 饭桌上可以这么说

- **同事局**：「它的目标是‘像真的’，不是‘是真的’。这俩大部分时候重合，分家的地方就叫幻觉。」
- **老板局**：「它像个特别自信的销售，不知道也会给你编一个听起来很专业的答案。」
- **亲戚局**：「跟那种记不清还硬要讲的人一样，讲得越顺越像真的。」

## 它到底怎么转的

回想上一篇：它在猜下一个词，依据是「什么样的话最像人话」。

当它读过足够多资料时，「最像人话」和「事实」高度重合，所以它答对。可一旦问题冷门、资料稀少，或者上下文里根本没有依据，它仍然会按同一个动作往下接——接出来的东西语法完美、格式正确、引经据典，只是那本书不存在。

它不是在骗你。**骗需要先知道真相，它没有这个负担。**

## 说到这儿就该停了

- **错**：「它数据库里没有这条，所以编了。」——它没有「查库」这个动作，除非你专门给它接了检索。
- **错**：「模型越大越不容易幻觉。」——通常更好，但不保证，尤其在它不熟悉的领域。
- **追问「那怎么避免？」** ——「让它给来源、允许它说不知道、关键结论人工核。前两条现在都还做不太好，所以第三条最靠谱。」

## 这个词是怎么被用坏的

「幻觉」是个太好用的词。答错了叫幻觉，是技术局限；答对了叫智能，是产品能力。同一个机制，两种命名，中间隔着一份新闻稿。

行业里最诚实的一句话大概是：**它一直在猜，只是猜对的时候，我们叫它智能。**
