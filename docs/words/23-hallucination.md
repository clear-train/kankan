# 幻觉

## 一句话

它从不撒谎，因为它分不清「像真的」和「是真的」——在它体内，这是同一个动作。

## 饭桌上可以这么说

- **同事局**：「它优化的是『像』，不是『对』。这两个词在它那儿只差一个字，在你这儿差一个项目。」
- **老板局**：「它是个从不承认自己不会的顾问。报价单还没看，方案已经写到第三版了。」
- **亲戚局**：「就像喝了二两、只记得个大概、偏要给你讲清楚的人。」

## 它到底怎么转的

上一篇说过，它在猜下一个词。这里要补一句：它没有「停」这个动作。人不知道怎么答的时候，会说「不知道」，那是另一条路。它只有一条路——往下接。

冷门问题、资料稀少、上下文里没依据，它照样接。接出来的东西语法完美、格式正确、引经据典，只是那本书不存在。而且它写得比真的还真，因为「真的」怎么写，它见得更多。

所以它不是在骗你。**骗需要先知道真相，它没有这个负担。**

## 说到这儿就该停了

- **错**：「它数据库里没有这条，所以编了。」——它没有「查库」这个动作，除非你专门给它接了检索。
- **错**：「模型大了就不会幻觉。」——它只是错得更像对的。低级错误变少，高级错误变贵。
- **错**：「跟它说『不要编造』就行。」——你这么一说，它只会把编造写得更客气。
- **追问「那怎么防？」**——「让它给来源、允许它说不知道、关键结论自己核。前两条它今天还做不利索，所以第三条是真话。」

## 这个词是怎么被用坏的

「幻觉」是个太划算的词。答错了，叫技术局限；答对了，叫智能涌现。同一个动作，两个名字，中间隔着一份新闻稿。

更划算的是它把责任挪走了：不是产品不准，是模型「产生幻觉」——像人发烧说胡话，你总不能怪病人。

行业里最诚实的一句话是：它一直在猜。猜对的时候，我们叫它智能。
