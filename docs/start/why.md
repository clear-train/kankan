# 为什么是饭桌

先说结论：这本书不教你成为 AI 专家。它教你别在饭桌上被忽悠，也别在饭桌上忽悠人。

## 饭桌是当代中国最诚实的技术发布会

一个新概念的生命周期大概是：论文里出现 → 技术圈讨论 → 媒体翻译 → 饭桌上第一次被提起 → 变成融资材料 → 变成家族群里的转发。

大多数人第一次听说「大模型」，不是在论文里，是在饭局上：有人放下筷子，说「现在这个 AI 啊」，然后所有人都看着他。

信息在这一站被压缩、变形、加料。有的变成神话，有的变成笑话。听的人都会记住，因为饭桌上的话，听起来总比文件里的话真。

原因不复杂：饭桌是唯一一个说错了基本不用负责、说对了立刻有人敬酒的场合。

## 为什么「侃侃而谈」值得认真对待

我一度觉得，饭桌上聊 AI 本质上是一种表演。后来发现不是。

一个人怎么谈 AI，暴露了他怎么理解三件事：技术是什么、工作是什么、人是什么。说「AI 就是个工具」的人和说「AI 要取代所有人」的人，对世界的假设完全不同。而这些假设，会变成他们明天做的决定——招不招人、投不投钱、学不学新东西。

说这些话的人，通常不觉得自己在做决定。这才是问题。

所以这不是一本装逼指南。装逼只是顺便发生的事。

## 这本书的立场

1. **说人话。** 一个比喻能讲清的，不堆第二个术语。
2. **承认不知道。** 尤其是预测未来的部分。
3. **警惕词。** 热词是通货膨胀，理解是通货紧缩。这本书干的是后一件事。

如果你读完只想记住一句，我希望是这句：

> 大部分关于 AI 的争论，争的不是 AI，是我们想要一个什么样的未来——只是大家不好意思直说。
