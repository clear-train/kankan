# 怎么用这本书

## 两种读法

**顺序读。** 从卷一「猜下一个字」开始。地基讲清楚之后，卷二的热词基本是复习——你会发现大部分概念只是同一个机制的不同说法。

**查着读。** 每个词条独立，饭局前翻三分钟也行。每篇都能单独看懂。

## 每个词条长什么样

- **一句话**：能背下来的版本，只有一句。
- **饭桌上可以这么说**：分场合的台词，直接复述，不用改编。
- **它到底怎么转的**：最小机制，配一个生活比喻。
- **说到这儿就该停了**：常见错误说法，以及被追问时怎么接。
- **这个词是怎么被用坏的**：一点反思，语气冷一点。

## 三条纪律

1. **不确定就说不确定。** 饭桌上最值钱的不是知识，是可信度。硬撑一次，后面全废。
2. **不用你解释不了的词。** 说「它在猜下一个词」比说「它有涌现能力」安全一百倍。
3. **讲完一个词就停。** 侃侃而谈的重点在「而谈」，不在「侃侃」。占着话头不放的人，最后都会被讨厌。

## 一个提醒

这本书不保证你在饭桌上受欢迎。

事实上，如果你真读懂了，你可能会比以前更沉默——因为你开始听得见那些话里的空转。那也是一种收获。
