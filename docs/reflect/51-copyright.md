# 版权与训练数据：先上车后补票

## 一个场景

阿岚接到老客户的电话，说新封面还想用「你那种感觉」，预算只有上次的十分之一。她问为什么。对方说：「现在有工具了，出图快。」她又问那还需要她做什么。对方说：「你把关一下就行，半天的事。」她挂了电话，站起来倒水，杯子满了还在倒，水顺着杯壁流到手上，凉的。她抽了张纸擦了一下，点开对方发来的附件。图的右下角有一行小字：参考风格，可商用。可商用三个字，她来回看了两遍。

## 它是怎么转的

很多人以为版权法没跟上 AI。其实它一直这么写：保护具体的表达，不保护风格。这条线不是漏洞，是设计——要是风格能垄断，画画的先互相告死。

过去这条线不疼，因为学一个人的风格很贵。看几百张画，练十年手，还不一定像。现在这份学费降到零，法律还是同一句话，只是开始收利息——而利息不是那张画，是画后面的人。

训练也不是抄。抄是复制那一张，训练是读完忘掉细节，只留下「这类图长什么样」。它拿走的不是画，是画与画之间的规律，像把所有菜尝了一遍，最后学会了盐的用量。

所以真正的损失不在法庭上，在报价单上：不是这张图被盗，是下一个客户不再需要你出手。而我们一边骂它，一边在赶稿的夜里让它出三版草稿。行业管这叫效率提升，你管这叫手熟不值钱了。

## 饭桌上可以这么说

- **同事局**：「它不抄那张画，它抄你画画的习惯。这个法律管不着。」
- **老板局**：「风格不受保护，能保护的是具体那张图。风险在法务，不在技术。」
- **亲戚局**：「像有人把你家菜谱看了一遍，然后开连锁店，说味道不一样。」

## 说到这儿就该停了

- **错**：「训练用了版权作品，就是侵权。」——要看输出和具体那张图是否实质性相似。训练本身怎么定性，各地还没定。
- **错**：「风格被抄了就能告。」——护的是表达，不是风格。能主张的是画面、构图、可识别的元素。
- **错**：「等法规清楚就好了。」——车已经在路上，补票的钱最后常由最没有法务的人出。
- **追问「那创作者怎么办？」**——「短期在合同里写清不许训练，中期要来源标注，长期谈分成。三样都没定型，先谈钱。」

## 最后

她把那张图拖进一个叫「参考」的文件夹。里面全是她自己的画。
