# 卷四 · 反思：把话说难听一点

前三卷教你怎么看懂，这一卷负责让你不安。不安不是因为 AI 会毁灭人类，是因为它正在改一些我们习以为常的东西：谁签字、谁练手、什么算原创、什么算学会。

这一卷没有答案，只有更清楚的问题。写的时候守一条：可以刻薄，不可以危险——不评价具体的人，不预测政策和行情，不给投资建议。

## 这一卷怎么读

顶上一排是全书八卷，点「反思」两边的字可换卷；左边是本卷篇目；右边「本页」是本文小标题。更完整的走法见[网站怎么用](/start/how-to-use#网站怎么用)。

每篇五节：一个场景 / 它是怎么转的 / 饭桌上可以这么说 / 说到这儿就该停了 / 最后。这一卷的「最后」通常最冷，建议先读它，再回头看场景——你会知道那个场景为什么会写成那样。

## 这一卷还缺什么

- **教育与孩子**。学生用它写作业，老师用它改作业，这一轮真正的实验场在学校，这一卷一篇都没写。
- **亲密关系**。陪伴那一篇在卷三讲的是生意，人为什么会跟它说心里话，还没人拆。
- **意义与宗教**。当「有人听你说话」变得无限便宜，倾诉这件事本身会怎么变。
- **医疗与法律的具体场景**。边界那篇立了框架，但真实诊室、真实法庭里的细节还没落。
- **语言与方言**。小语种在训练数据里的比例，决定了谁的口音会被听错。
- **我们自己**。这本书记了几十次「他们怎么用坏一个词」，还没写过一次「我们为什么需要它」。

缺口按「不写会误导读者」的程度排。最后一条最靠后，也最难写。
