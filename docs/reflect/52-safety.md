# 安全与末日论：谁在害怕什么

## 一个场景

茶歇，两个人站在咖啡机旁边。一个说「再不管，这东西迟早出人命」，语速很快。另一个等他说完，把杯子放回托盘，磕了一声：「你说的那个风险，我这辈子大概看不到。我这个月要处理的，你一条没提。」「那你说。」「上周有人拿它冒充我们客服，骗走了两个客户的账号。」咖啡机响了一声。第一个人说：「那是应用层的问题。」然后去拿了个牛角包。旁边端咖啡的实习生，走也不是，留也不是，手里的杯子一直没放下。

## 它是怎么转的

我们怕的东西长得很具体：一个比人聪明的机器，决定不再听人的。这个画面好卖，也好拍。但它需要一样东西——意图。而机器最缺的就是这个，它连「今天要不要罢工」都想不到。

现实里的伤害大多不需要意图。它按概率接话，接错一句，客服把退款打给了骗子；它执行指令又快又准，把一个小错误放大一万倍。灾难不需要恨你，只需要不看着你，而「不看着」从来不算过错。

所以「安全」底下压着三件事：会不会被绕过，会不会被人拿去做坏事，会不会自己乱来。公共讨论几乎全给了第三件，因为只有它像电影，而电影卖票。

另外两件不出新闻，只出现在值班表和事故报告里。我们愿意谈哪一件，常常取决于谈哪一件能让我们显得重要。毕竟讨论天网，不需要有人值班。恐惧是有分工的：有人负责想象最坏的，有人负责处理已经发生的。

## 饭桌上可以这么说

- **同事局**：「安全分三层：会不会被绕过、会不会被人拿去做坏事、会不会自己乱来。」
- **老板局**：「我担心的不是天网，是有人拿它冒充我们客服。」
- **亲戚局**：「现在最现实的危险是骗子，不是机器人造反。」

## 说到这儿就该停了

- **错**：「敢谈末日论的人是清醒的。」——谈风险不等于懂风险。要看他能不能说出可以测的东西。
- **错**：「说 AI 危险就是反技术。」——多数安全研究是在争取时间，不是在反对进展。
- **错**：「AI 没有意识，所以没有危害。」——危害主要不来自它想不想。
- **追问「那到底该怕什么？」**——「怕责任不清。出了事，说不清是用户、公司，还是模型自己的判断。」

## 最后

散场时在电梯口又碰见了。一个在回消息，一个在等电梯。谁都没提安全。
