# 第二个土木

## 一个场景

表姐的儿子今年高考，分数刚够得着一所 985 的计算机。饭吃到一半，她把手机推过来：「你给看看，现在学计算机还行吗。」

桌上静了两秒。姑父先开口：「当年土木也这么热。」他说这话时没什么表情。

我夹了一筷子菜，想起上个月在面试间里见过的一个人。三十出头，简历上写着土木，现在转做数据处理。他说他们那一届也觉得困难是暂时的，等他们毕业，工地会重新忙起来。他说完，把简历翻了一页。

## 它是怎么转的

土木的教训，不是「行业不行」。行业行不行是结果，机制在别处：培养周期和行情周期对不上。

十八岁填志愿，家长看的是这一轮的行情。读完四年，赶上行业下行，再读三年硕士，行情又换了一轮。等到毕业那年才发现，当年劝他报的人，早已不在这个行业里；卖这门生意的，不回访，不退款。

三件事同时到齐：学历和证书通胀，本科不够用，硕士起步，注册证一张张考；岗位收缩，设计院和施工单位一起减员；转行成本高，画图、规范、现场经验，都绑在工地上，换一行等于从零开始。单拎任何一件都不致命，三件叠在同一年毕业的人身上，才叫塌。

有数字可查。2022 年，全国房地产开发投资比上年下降 10.0%，房屋新开工面积下降 39.4%（[国家统计局](https://www.stats.gov.cn/xxgk/sjfb/zxfb2020/202301/t20230117_1892126.html)）。同年河南本科一批投档，一所土木学科常年排在最前面的高校，理科最低位次比上一年掉了四万多名，它的土木类在征集志愿里还剩计划余额（[澎湃新闻的报道](http://edu.youth.cn/wzlb/202207/t20220727_13876630.htm)）。

计算机现在有同样的形状：也是四年，也是按上一轮的行情填志愿，也是扩招。不一样的地方只有一处，软件技能能搬走。写代码这件事，可以搬去制造业、医疗、金融、物流，手艺还在。土木的资产搬不走，图纸带得走，工地带不走。

所以计算机更可能不是「土木第二」，是「更慢的土木」。需求方更分散，痛感被摊薄，不容易一次性塌下来，但也谈不上安全。

## 饭桌上可以这么说

- **同事局**：「土木的教训不是选错行，是四年太长，行情太短。」
- **老板局**：「别问哪个专业热，问他四年后拿什么换饭吃。能搬走的那部分才值钱。」
- **亲戚局**：「学计算机是一门能带走的手艺，不是铁饭碗。指望它保一辈子，哪个专业都保不了。」

## 说到这儿就该停了

- **错**：「学计算机就是下一个土木。」——形状像，落点不同。软件技能跟着人走，土木的资产跟着工地走。
- **错**：「土木不行是因为房地产不行。」——房地产是导火索，机制是学历通胀、岗位收缩、转行成本三样同时到齐。
- **错**：「选对专业就稳了。」——十八岁填的表，赌的是二十八岁的市场，没人能替你保这个险。
- **追问「那到底该不该报计算机」**——「先看他能不能自己坐下来写点东西。能，这门手艺至少能带走；不能，换哪个专业都一样。」

## 最后

填志愿这事，最像买楼花：交钱的时候看的是样板间，交房的时候看的是工地。区别是，楼花烂尾了还能拉横幅，志愿填错了，只能自己再读四年。
