# 这一卷会过气

前四卷写的词，目标是十年后还能用。这一卷反过来：它专门收录正在刷屏的东西——一篇被转发的公众号长文、一场直播、一部突然爆的短剧、一个全网都在用的说法。

**它的价值不在准确，在及时。** 所以每一篇都标了写作日期和预计保质期，过期了就挪进归档，留在原地，不删。

## 为什么值得单独一卷

因为饭桌上真正被提起的，很少是「什么是 Transformer」，多半是「你听说李佳琦卖 Token 了吗」。

热词会过气，但**热词为什么会在那一刻被大量转发**，这个规律不怎么变。所以这一卷表面在记新闻，实际在记的是一件事：什么样的说法，能在这个时刻穿过人群。

## 每一篇的固定结构

- **发生了什么**：只写可核查的部分，带链接和日期，不带形容词。
- **大家怎么说**：把互相打架的两种解释都摆出来，先不判。
- **拆开看**：用前四卷的机制去解释，指出两边都漏掉的那一层。
- **一年后再看**：给出可验证的判断和验证时间。写错就认，下次回来改。
- **这一篇的保质期**：明确写它什么时候过期，过期标志是什么。

## 收录标准

三条，缺一条就不收。

一，**它得能被一句话复述**。转发量再大，说不出重点的，不算。
二，**它背后有一个机制，而不只是一件热闹**。热闹归微博，机制归这里。
三，**它不越界**。涉及未经证实的指控、私人生活、外交与情报传闻的，一律不写——不是怕，是这种题材在饭桌上没有安全的下半句。

写之前先看[引用规范](/citation)。这一卷对链接的要求比其他卷更严，因为数字会动。
