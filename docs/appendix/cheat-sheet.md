# 一分钟速查

上桌前三十秒，先扫最后一列。找到你今晚要坐的那张桌子，从那几行里挑三行记住，剩下的不用背。

背了也用不上。你只需要在别人说完之后，有一句话可以接。

| 词 | 一句话 | 饭桌上怎么说 | 场合 |
| --- | --- | --- | --- |
| 猜下一个字 | 它不是在回答，是在接话。 | 「它不是在回答你，它是在接你的话。」 | 全员 |
| Token | 它按碎片算钱，不按你的意思算。 | 「你跟它说话，是按碎片计价的，不是按句。」 | 同事局 |
| 神经网络 | 它不模仿大脑，它只是台拟合机。 | 「一层层加权，中间拐个弯。名字叫神经，干的是拟合。」 | 技术局 |
| 训练 | 训练不是上课，是遮住后半句让它猜。 | 「训练是一次性的大钱，用起来才是每天的水电费。」 | 老板局 |
| 参数与向量 | 意思能算成距离，算不出对错。 | 「每个词是空间里一个点。近义词住得近，仅此而已。」 | 技术局 |
| 算力 | 算力贵在等：几千张卡互相等结果。 | 「单卡快只算一半，卡之间一堵，几千张一起等。」 | 老板局 |
| 开源与闭源 | 开放权重给你成品，顺手把责任也给你。 | 「像餐馆公布菜谱和只卖成品。两门生意，不是两种品德。」 | 亲戚局 |
| 大模型 | 读完全网，它只学会了接话。 | 「一个读完全网的实习生：记性好，没常识，特别会顺着你说。」 | 全员 |
| 提示词工程 | 没有咒语，只有没写清楚的需求。 | 「角色、任务、约束、例子。四样给全，返工少一半。」 | 同事局 |
| 上下文窗口 | 它不记得你，它只是又被喂了一遍。 | 「它没有记忆，只有一张桌子，每问一句都得重摆。」 | 同事局 |
| 幻觉 | 它不撒谎，它分不清像和是。 | 「它优化的是像，不是对。差一个字，差一个项目。」 | 全员 |
| 温度 | 它调的是胆子，不是才华。 | 「同一个问题两遍答案不一样，多半是温度没调低。」 | 同事局 |
| 微调 | 微调教它怎么说，不教它说什么。 | 「想让它换说法就微调，想让它知道新事实就去检索。」 | 老板局 |
| RAG | 开卷考试，翻错页也答得理直气壮。 | 「翻对了顺水推舟，翻错了照样答得理直气壮。」 | 技术局 |
| 向量数据库 | 它量的是距离，不是意思。 | 「几千条数据别上它，放进表格全算一遍更快。」 | 技术局 |
| 多模态 | 看得懂和画得出，隔着一条产线。 | 「看得懂照片，和能画出一张照片，中间隔着一条产线。」 | 亲戚局 |
| 推理模型与思维链 | 它在写草稿，草稿不等于演算。 | 「草稿写得工整，不等于真懂。方向错了，越长越远。」 | 同事局 |
| Agent | 它替你动手，而且不觉得自己错了。 | 「错了你一眼能看出来的活可以给它，动钱动库还得你守着。」 | 老板局 |
| 多智能体 | 不是开会，是各交作业再加个判卷的。 | 「删掉讨论那层，成绩不掉，说明讨论是表演。」 | 技术局 |
| 智能组织 | 不是让 AI 替员工干活，是让公司记住自己怎么干活。 | 「新来的人三个月能做到老人八成吗，做不到就是买了软件。」 | 饭局通用 |
| MCP 与工具调用 | 它只会喊要调哪个函数，动手的是外面。 | 「MCP 像 USB-C：解决接线，不解决信任。」 | 技术局 |
| MoE、蒸馏与量化 | 变小不是变强，是三处各砍一刀。 | 「三种省钱法都拿能力换成本，宣传页只印省下的那半句。」 | 技术局 |
| 对齐与 RLHF | 它学的不是善恶，是我们爱听什么。 | 「对齐不是装道德，是让它猜中我们要什么，包括没说出口的。」 | 哲学局 |
| Scaling Law | 它保的是平均分，不保你那一题。 | 「趋势是真的，斜率在变。具体到某个能力，只能测不能推。」 | 老板局 |
| AGI | 人人说它重要，没人说得清是什么。 | 「能干活和有没有意识是两个问题，多数争论把它们搅在一起。」 | 哲学局 |
| 决策模型 Jev | 它不写字，只给选择、分数和真假。 | 「慢思考交给大模型，快判断交给决策模型，这是分工不是替代。」 | 技术局 |
| JEPA | 它猜的不是下一个字，是下一帧在心里长什么样。 | 「视频生成得像，不等于物理判断得对，这两件事老被混着说。」 | 技术局 |
| Harness | 模型是发动机，壳才是变速箱。 | 「同一个模型换个壳，跑分能差出一截。」 | 技术局 |
| 模型路由 | 先用便宜的判断，决定要不要叫贵的。 | 「它是前台不是经理：先看你是谁，再决定叫谁出来。」 | 老板局 |
| 上下文工程 | 提示词管嘴，它管眼睛。 | 「先让它看见什么，比教它怎么说更要紧。」 | 同事局 |
| 后训练 | 考前突击，突击的科目得能对答案。 | 「能自动判对错的活，它进步最快。」 | 技术局 |
| 评测污染 | 分数涨了，可能只是题做过了。 | 「榜单是市场部的资产，不是工程部的指标。」 | 老板局 |
| 端侧模型 | 不是把大模型塞进手机，是把问题改小。 | 「卖点是延迟和数据不出门，不是参数。」 | 同事局 |
| 合成数据 | 没有判卷人的地方，它造的是车轱辘话。 | 「成本从人力账搬到显卡账上。」 | 技术局 |

这张表最多撑过一轮追问。到了第二轮，说「这个我得回去查」，比硬接体面。
