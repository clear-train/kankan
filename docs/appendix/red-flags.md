# 反装逼清单

这张单子不是让你去拆台，是让你在点头之前多停半秒。

每条的「因为」写的不是对错，是他为什么会这么说。

## 关于模型本身

- 听到「参数千亿级」，先别信。因为参数是容量，说大了不用负责。
- 听到「参数越多越聪明」，先别信。因为数参数比数效果便宜。
- 听到「它会思考」，先别信。因为「思考」比「接话」好卖。
- 听到「温度调高更聪明」，先别信。因为「创造力」得有个滑块。
- 听到「思维链越长越准」，先别信。因为长草稿看起来更像在想。

## 关于他们家的方案

- 听到「上 RAG 就不幻觉了」，先别信。因为手里有引用，编起来更有底气。
- 听到「我们做了行业大模型」，先别信。因为微调加检索，说成行业更贵。
- 听到「微调过，公司知识都进去了」，先别信。因为知识会变，训进去就改不动。
- 听到「上了向量库，问答就准了」，先别信。因为捞得准，不等于答得对。
- 听到「Agent 能自己进化」，先别信。因为「会循环」解释起来太麻烦。
- 听到「接上 MCP 就会用工具」，先别信。因为真正动手的是外面那层程序。

## 关于成本与开源

- 听到「开源模型马上就追平了」，先别信。因为追平看榜，不看运维。
- 听到「开源就是免费」，先别信。因为账单上只有权重那一行是零。
- 听到「开源更安全，能审查」，先别信。因为能审查和有人审查是两件事。
- 听到「量化无损」，先别信。因为掉点的地方，宣传页不测。
- 听到「MoE 是很多小模型投票」，先别信。因为「投票」比「挑专家」好懂。

## 关于未来

- 听到「规模上去，能力自然上去」，先别信。因为平均分涨了，单科可以不涨。
- 听到「AGI 三五年就到」，先别信。因为说「不知道」上不了台。
- 听到「对齐就是装道德」，先别信。因为说「偏好统计」没人鼓掌。
- 听到「多模态模型会画画」，先别信。因为产品把它打包成了一个按钮。

清单的用处是让你少点一次头，不是让你多赢一场辩论。
