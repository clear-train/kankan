# 注意力：一句话里，谁该看谁

## 一句话

每个词先问一句「我该听谁的」，再按相关度把别人的话掺一点进来。

## 饭桌上可以这么说

- **同事局**：「它在句子内部做分工：每个词看一眼全场，挑相关的取个加权平均。Transformer 就是把这一层堆起来。」
- **老板局**：「它治的是长句忘前面。能同时看全场，就能并行算；能并行，才堆得深。」
- **亲戚局**：「像开会，所有人都能听见所有人说话，但只记跟自己有关的，记完再发言。」

## 它到底怎么转的

每个词先备三样东西：一句「我要找什么」，叫查询；一句「我有什么」，叫键；还有它真正的信息，叫值。拿甲的查询，去和每个词的键比像不像，像的打高分；分数换成百分比，再按百分比把所有人的值搅在一起，就是甲在这一层的新内容。

这也是招聘：查询是岗位要求，键是简历上的关键词，值是这人真会的东西。最后交到你手上的不是「最匹配的那个人」，是所有候选人按匹配度加权出来的一个合成人。自注意力就是这件事。

一句话里所有词同时做一遍，是一层；一层里开几组不同的招聘标准，再拼回去，是多头。层叠几十层，就是 Transformer 的主结构。顺序它自己不知道，得靠位置编码另外喂进去。

## 说到这儿就该停了

- **错**：「注意力就是理解。」——它是一次分配：这一层的输出里，谁的信息占几成。分配得准，不等于懂因果。
- **错**：「它能看无限长。」——它确实看全场，但开销随长度平方涨，太长的文本用不起。
- **错**：「多头就是好几个模型。」——是同一层里几组查询和键，最后拼回一个向量，还在一个模型内。
- **追问「那它凭什么管用？」**——「因为一句话里该看谁，基本由上下文决定。它把这件事交给数据学，不写死成语法规则。」

## 多说一句

「注意力」这个词选得漂亮，也骗人。它听着像专注，实际是一次加权平均：谁被看见，取决于查询和键有多像，而「像」是训练出来的。所以它常常看对，也常常看得太齐——重复的词互相捧场，长文里开头那几句被越埋越深。后来那些上下文窗口、检索、压缩，干的多半是给这件事打补丁。
