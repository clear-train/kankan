# Token：AI 眼里的世界是碎的

## 一句话

它读的不是字，是可以计价的碎片；你跟它说话，其实是在过磅。

## 饭桌上可以这么说

- **同事局**：「一个汉字常拆成一到两块。你写一副对联，在它那儿是按块称的。」
- **老板局**：「提示词写得越长，账单越厚。它不嫌你啰嗦，它按啰嗦收费。」
- **亲戚局**：「跟寄快递一样，不看东西贵不贵，只看几斤。」

## 它到底怎么转的

模型不认识汉字，也不认识字母，只认识编号。中间有个分词器，先把文本切成碎片，每块编一个号。像把一篇文章拆成一盒乐高，之后所有计算都在这盒零件上做。

切法很功利：常见的词整块留下（「the」「中国」），生僻的拆开（「魑魅魍魉」多半被拆成好几块）。所以同一段话，中文和英文、这个模型和那个模型，块数都不一样。

这事值得知道，因为上下文窗口、计费、生成速度，全按块数算。你以为在跟它「说话」，其实你在往一个计价器里倒碎片。**它没有「字」的概念，只有「块」的账。**

## 说到这儿就该停了

- **错**：「一个汉字就是一个 token。」——常见汉字大多一到两块，标点、空格、换行也照样算。
- **错**：「token 就是词。」——它是模型认为该放一起的碎片，跟语言学上的词没关系。unbelievable 可能是三块。
- **错**：「按字数估成本就行。」——按字数估，中文会差出一截。它数的是碎片，不是你数的那种字。
- **追问「那 100 万 token 是多少字？」**——「中文大概几十万字，一个字一到两块估，别精算，会算哭。」

## 多说一句

token 在 AI 圈是计价单位，在币圈是一张彩票。同一个词，两拨人各说各的，谁也不觉得对方在说外语。词典追认得很晚，等它追上，词已经换了两茬，注解还留着上一茬的。所以下次听到「我们的 token 经济」，先问一句：你说的是哪一种。问完多半会冷场，但冷场比点头便宜。
