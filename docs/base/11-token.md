# Token：AI 眼里的世界是碎的

## 一句话

AI 不按字读，按碎片读；一个字、半个词、一个标点，都可能是它眼里的一个 token。

## 饭桌上可以这么说

- **同事局**：「跟它聊天是按 token 收费的，但 token 不等于字。中文一个字经常占一到两个 token，英文一个长词可能被切成三四块。」
- **老板局**：「成本按 token 算。提示词写长了、上下文塞满了，都是钱，跟电话费一个道理。」
- **亲戚局**：「就跟短信按条收费差不多，只不过它那条特别短。」

## 它到底怎么转的

模型不认识汉字，也不认识字母，只认识数字。所以先要有个「分词器」，把文本切成碎片，每块编一个号。

切法很功利：常见的词整块留下（「the」「中国」），生僻的拆开（「魑魅魍魉」很可能被拆成好几块）。结果就是，同一段话，中英文、不同模型，切出来的块数都不一样。

为什么这事值得知道：上下文窗口、计费、生成速度，全都按 token 计。你以为你在跟它「说话」，其实你在往一个计价器里倒碎片。

## 说到这儿就该停了

- **错**：「一个汉字就是一个 token。」——常见字大多一到两个 token，标点、空格、换行也算。
- **错**：「token 就是词。」——不是。它是「模型觉得应该放在一起的碎片」，跟语言学上的词没关系。
- **追问「那 100 万 token 是多少字？」** ——「中文大概几十万字，按一个字一到两个 token 估就行，别精确算，会算哭。」

## 多说一句

token 这个词，在 AI 圈是计量单位，在币圈是另一个故事。同一个词，两种命运，都挺能说明「词是人用的」——谁用得多，就是谁的意思。
