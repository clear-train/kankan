# 一切从「猜下一个字」开始

## 一句话

它不是在回答问题，是在接住你的话；答案只是接得准的副产品。

## 饭桌上可以这么说

- **同事局**：「它没有『回答』这个动作，只有『往下接』。接得准了，我们管这叫懂。」
- **老板局**：「它像永远不冷场的实习生。你说上半句，他接下半句，接完自己也不确定对不对。」
- **亲戚局**：「跟手机输入法猜你下一个词一个道理。区别是它读的书，一个人几辈子读不完。」

## 它到底怎么转的

你打「今天天气」，输入法跳出「不错」。它不知道今天什么天气，只知道这四个字后面最常跟着什么。大模型是同一个动作，只是把「最常跟着」换成了一个几十层深的函数。

函数吐出来的不是一句话，是一张表：下一个碎片是「的」的概率 0.31，是「了」的 0.12，是「猫」的 0.0004。按概率挑一个接上，再算下一个。你看到的一整段，是这么接了几百次的结果。

为了接得准，它被迫把语法、事实、语气、逻辑都压进参数里。没人教它「北京是中国的首都」，但这句话在网上出现太多次，不学会就接不准下一句。**所以它不是知道，是熟悉。**

## 说到这儿就该停了

- **错**：「它在思考。」——它在按概率接话。思考是你替它做的翻译，也是厂商替它做的文案。
- **错**：「它把整本书背下来了。」——参数不是硬盘，存的是规律不是原文。它记住的是「这类句子长什么样」。
- **错**：「它答对了，说明它懂。」——答对只说明这一步接得准。下一句它照样可能拐进沟里。
- **追问「那它为什么能写代码？」**——「代码也是一种语言。它见过太多代码，知道下一行大概率长什么样。能不能跑，得编译器说了算。」

## 多说一句

这个机制最反直觉的地方，是它没有一个叫「理解」的开关。你看到的理解，是猜得准之后剩下的东西。所以别问它懂不懂，问它下一步接得准不准——这个问题有答案，而且能验。至于我们为什么非要问「懂」，那是另一个话题，通常跟它无关，跟提问的人有关。
