# 一切从「猜下一个字」开始

这一篇不长，但它是整本书的地基。看懂了它，后面所有热词都会自动降级为「一种猜法」。

## 一句话

大模型做的唯一一件事，是看着前面的字，猜下一个字。

## 饭桌上可以这么说

- **同事局**：「它不是在给答案，它是在接话。接得足够多，看起来就像想过了。」
- **老板局**：「它像个特别会聊天的实习生，你说上半句，他总能接下半句，但他不一定知道自己在说什么。」
- **亲戚局**：「跟手机输入法猜你下一个词一样，只是它读的书多到离谱。」

## 它到底怎么转的

输入法联想，你天天在用。打「今天天气」，它跳出「不错」。它并不知道今天的天气，它只知道这四个字后面最常跟着什么。

大模型是同一个动作，只是规模大了很多：读过的文本多到人一辈子读不完，参数量大到能记住极细的语言规律，然后把这套「什么后面接什么」的直觉压进一个巨大的函数里。

关键在于：为了猜准下一个词，它被迫学会了语法、事实、逻辑、甚至语气。没有人教它「北京是中国的首都」，但这句话在网上出现了太多次——不学会它，就猜不准下一句。

**所以它不是知道，是熟悉。** 这两个词的差别，是后面所有翻车点的源头。

## 说到这儿就该停了

- **错**：「它在思考。」——准确的描述是「它在按概率接话」，思考是你加的注解。
- **错**：「它把整本书背下来了。」——参数不是硬盘，存的是规律不是原文。它记住的是「这类句子长什么样」。
- **追问「那它为什么能写代码？」** ——「代码也是一种语言。它见过太多代码，知道下一行大概率长什么样。」

## 多说一句

这个机制听起来很笨，但它解释了一个反直觉的现象：模型越大，表现越好，不是因为记住了更多答案，而是因为它必须理解更多结构才能把下一个字猜准。

笨办法做到极致，看起来就像聪明。这句话你可以留着，后面很多地方用得上。
