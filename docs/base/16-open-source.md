# 开源与闭源：不是道德问题，是生意问题

## 一句话

开放权重只是把成品递给你，不等于把做法也递给你。

## 饭桌上可以这么说

- **同事局**：「能下载权重叫开放权重，不叫开源。训练数据、代码、配方，多数没给。」
- **老板局**：「闭源买的是稳定和托管，开源省的是授权费，赔的是人力和运维。」
- **亲戚局**：「像餐馆公布菜谱和只卖成品，两门生意，不是两种品德。」

## 它到底怎么转的

开源软件讲四项自由：随便用、随便改、随便分发、随便研究。放到模型上，这四项很难全给。训练数据牵着版权和隐私，训练细节是竞争力，权重给了，配方还在自己手里。

所以「开放权重」是个更准确的说法：成品给你，做法不给。它确实把「模型」这一层变便宜了，但数据、场景、算力、工程仍然贵。下载一个权重文件和把它跑进生产环境，中间隔着几个月和几个人。

闭源卖的是稳定和托管：不用自己运维，有服务承诺，出事有人接电话。两者不是善恶对立，是成本转嫁方式不同。开源把运维成本转给你，闭源把它折进账单。你要选的不是立场，是哪笔账你更付得起。

## 说到这儿就该停了

- **错**：「开源就是免费。」——权重免费，算力、人力、合规都不免费。
- **错**：「闭源就是黑心。」——它卖的是托管和责任，有人愿意为这个付钱。
- **错**：「开源更安全，因为能审查。」——能审查不等于有人审查。权重放出去，也收不回来。
- **追问「那我该用哪个？」**——「看你有没有人。有人运维、数据敏感，用开放权重；没有，就买托管。」

## 多说一句

对普通人的实际影响是三件事：便宜、可以自己部署、责任在你自己。第三条最容易被忽略。闭源出问题，你可以骂厂商；自己部署的模型胡说八道，只能自己写检讨。开源把权力给了你，顺手把责任也塞了过来。
