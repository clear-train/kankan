# 算力：为什么这玩意儿这么贵

## 一句话

它贵不是因为芯片快，是因为成千上万张卡得同时算一件事，还得不停对表。

## 饭桌上可以这么说

- **同事局**：「GPU 是几千个小工一起搬砖，CPU 是几个老师傅。训练要搬砖，不要老师傅。」
- **老板局**：「训练是买生产线，推理是每件货的电费。只算前一笔，后一笔会自己找上门。」
- **亲戚局**：「跟开工厂一样，机器一开就烧电，停着也烧钱。」

## 它到底怎么转的

CPU 有少量强核，擅长串行、判断、处理复杂分支；GPU 有大量弱核，擅长把同一种简单运算同时做几千遍。神经网络的活儿主要是矩阵乘法，正好是后者。一个老师傅算一页账，和一千个人各算一列，是两种活。

训练要成千上万张卡一起跑。卡和卡之间得同步梯度，也就是各自算出的修正量；通信一堵，再快的卡也得等着，这叫通信瓶颈。另一个硬限制是显存：模型和中间结果装不下，就根本训不动，不是慢，是放不下。

推理便宜些，但按 token 摊，用的人越多越贵。电费、机房、散热、设备折旧，都要摊进去。「大力出奇迹」这句话，技术上有一半是真的，另一半是账单。

## 说到这儿就该停了

- **错**：「算力就是芯片快不快。」——单卡快只是一半。卡间通信、显存容量、机房供电，才是常见的瓶颈。
- **错**：「模型训完就没什么成本了。」——推理是长期开销。用户量涨，账单跟着涨。
- **错**：「堆卡就能解决一切。」——卡多了通信更堵，效率不是线性往上走的。
- **追问「那为什么小模型也能用？」**——「很多活不需要通才。小模型便宜、快，够用就行。」

## 多说一句

「大力出奇迹」的问题不在技术，在主语：谁有那个力。规模确实带来可预测的提升，这点有实验撑着；但能持续掏钱的机构是少数。对大多数团队，功夫在数据、场景和工程里，不在卡的数量上。这句话当规律讲很容易，当预算讲很难。难的那部分，通常不出现在 PPT 里。
