# 卷三 · 生意：钱从哪来，谁在付

卷一是它怎么转，卷二是它叫什么。这一卷只问两件事：钱从谁的口袋里出来，出来之后换到了什么。

发布会讲的是模型，生意讲的是账期。同一个功能，to C 是按月扣费、说停就停；to B 是招投标、验收、回款，一轮走完一年。看懂这一层，饭桌上听到「我们今年 AI 收入翻了三倍」，你会先问一句：翻的是收入，还是合同额。

## 这一卷怎么读

顶上一排是全书八卷，点「生意」两边的字可换卷；左边是本卷篇目；右边「本页」是本文小标题。更完整的走法见[网站怎么用](/start/how-to-use#网站怎么用)。

每篇五节：一个场景 / 它是怎么转的 / 饭桌上可以这么说 / 说到这儿就该停了 / 最后。重点看第二节——把一个生意拆到「谁付钱、付给谁、为什么现在付」，比记住产品名有用得多。

## 这一卷还缺什么

- **企业采购的真实流程**。现在写的是「为什么难」，没写「单子怎么签」：谁发起、谁评估、谁签字、预算从哪个科目出。
- **开源的生意**。权重免费之后，公司靠什么收钱，这一卷只有卷一的《开源与闭源》从技术上说过，没从账本上说过。
- **广告与订阅**。这是 to C 的两条命脉，现在只在别处顺带提过。
- **落地的行业**。制造、医疗、教育、法律，各有一套完全不同的验收标准，现在一篇都没有。
- **中间商**。外包公司、集成商、标注厂，这一层撑着大量就业，也最先被压价。

排序按「饭桌上被问到的频率」排，不按行业热度。
