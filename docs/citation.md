# 引用规范

这本书不追新闻，但会引用新闻、论文、官方文档和判例。凡引用，必须能被读者点开、原文可查。

一句话：**没有链接的事实，不许写成事实。**

## 一、什么必须给链接

以下内容只要出现在书里，后面就要跟一个可点击的链接：

- 具体数字：参数量、用户数、收入、价格、占比、耗时、成本
- 具体日期：发布、上线、判决、政策生效
- 版本号与产品名：某个模型、某个版本、某个工具的具体能力
- 研究结论：论文、榜单、实验数据
- 法律与监管：条文、判例、监管公告
- 任何「某个公司说了什么」「某个人说了什么」的原话

判断标准很简单：**这句话如果被人截图发到群里，对方能不能顺着链接自己核实。**

## 二、怎么选源

按优先级从高到低：

1. **一手来源**：论文（arXiv、期刊）、官方博客与文档、财报与招股书、法院文书、监管机构公告、公司公告。
2. **权威二手**：通讯社、主流媒体的原始报道。引用时必须写出处，并尽量再链回一手材料。
3. **不要用**：内容农场、聚合号、没有署名的「据悉」、AI 生成的摘要页、需要登录才能看的付费墙文章（除非同时给出一手替代）、短链与网盘链接。

链接一律用原始 URL，不用跳转短链，不用图片截图代替文字出处。

## 三、怎么写

正文里用 Markdown 行内链接，把链接挂在关键词上，不把裸 URL 摊在句子里：

```md
据 OpenAI 2024 年 5 月发布的[模型卡](https://openai.com/index/hello-gpt-4o/)，……
```

篇末统一列出处，格式：

```md
## 参考

- OpenAI, *Hello GPT-4o*, 2024-05-13. https://openai.com/index/hello-gpt-4o/（访问于 2026-11-10）
- European Commission, *AI Act*, 官方页面. https://digital-strategy.ec.europa.eu/en/policies/regulatory-framework-ai（访问于 2026-11-10）
```

要求：

- 作者/机构、标题、日期、链接，四件齐。
- 标注**访问日期**。网页会改，读者需要知道你看到的是哪一版。
- 链接失效时，删掉引用或换成可访问的存档（如 web.archive.org），不要留一个死链当装饰。

## 四、两个常见错误

**错误一：把结论写成常识。**
「业内普遍认为参数越多越好」——谁认为？在哪说的？没有出处就是作者自己的印象。改成「参数多不等于更强（见 [出处]）」，或者直接删。

**错误二：用二手转述当一手。**
「据某媒体报道，某论文发现……」——直接链论文。二手转述会丢限定条件，而限定条件往往才是结论的全部。

## 五、政治与监管题材

- 只引**官方原文**：监管机构公告、法规文本、法院判决书。
- 不引解读类文章去推测政策意图，不写「这说明了什么信号」。
- 描述规则时用中性动词：规定、要求、禁止、生效。不用「打压」「围堵」「收割」这类带立场的词。
- 涉及争议话题，只写「规则存在」和「谁在承担成本」，不评价应当与否。

## 六、自检

写完一篇，问三个问题：

1. 文中的每个数字，我能不能点开一个链接核对？
2. 有没有「据说」「有研究表明」「业内认为」还活着？
3. 我引的是原文，还是别人对原文的转述？

三个问题有一个答不上来，就改到能答上来为止。
