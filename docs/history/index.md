# 这一行只有八年，已经有家谱了

2018 年，做语言模型还是一个任务一个模型。2026 年，随便一个聊天框背后都是一整套预训练、对齐、推理的服务。八年，够一门手艺换代一次，也够它积出一堆祖宗。

饭桌上问「哪家的」，其实是在问家谱：它爹是谁，它为什么长这样，它当年赢在哪，现在欠着什么。

这一卷就是这本家谱。六个模型，两个人。

## 这一卷怎么读

顶上一排是全书八卷，点「家谱」两边的字可换卷；左边是本卷篇目；右边「本页」是本文小标题。更完整的走法见[网站怎么用](/start/how-to-use#网站怎么用)。

**模型篇**（70–75）六节：它的来路 / 当年为什么这么做 / 走对的和走岔的 / 现在还剩什么 / 饭桌上怎么说 / 时间线。看重点是第三节——每一家的分岔，当年都只是一次取舍，回头看才叫分岔。

**人物篇**（76–77）五节：他是谁 / 他信什么 / 对在哪，错在哪 / 他为什么这么说 / 饭桌上怎么说。这一行里，人比参数更能解释选择：同样是看到那条曲线，有人去做产品，有人去做安全，有人去做世界模型。

**时间线**每条都带出处。年份、参数量、金额这类数字，能查到原文才写；查不到就不写，写在文里比写错强。

## 收录标准

一、**能一句话说完它赢在哪**。说不出，说明还没看懂，不写。

二、**带得出一条取舍**。当年那个选择，在当时是不是也说得通；如果它只是运气好，就不是家谱，是传说。

三、**数量能数清**。模型收六家，人收两个。再多就成了公司名录，读者记不住，我也不想写。

## 一条纪律

这一卷最容易写错，因为年份、参数、发布会细节全都有据可查，而人的记忆靠不住。所以：每个数字后面都有链接；两个来源打架时，把两个都写出来，不替谁圆；发现自己写错了，直接改，改动记在[更新日志](/updates)。

家谱不是用来背的。它的用处是：下次有人说「某家突然就起来了」，你能说出它憋了几年，以及它在哪一年做过一个当时看起来很不划算的决定。
