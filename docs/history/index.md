# 这一行只有八年，已经有家谱了

2018 年，做语言模型还是一个任务一个模型。2026 年，随便一个聊天框背后都是一整套预训练、对齐、推理的服务。八年，够一门手艺换代一次，也够它积出一堆祖宗。

饭桌上问「哪家的」，其实是在问家谱：它爹是谁，它为什么长这样，它当年赢在哪，现在欠着什么。

这一卷就是这本家谱。已经收到二十四篇：十五个模型与事件、五家公司、四个人。

## 这一卷怎么读

顶上一排是全书八卷，点「家谱」两边的字可换卷；左边是本卷篇目；右边「本页」是本文小标题。更完整的走法见[网站怎么用](/start/how-to-use#网站怎么用)。

**模型篇**（70–75、78–83、91–92）六节：它的来路 / 当年为什么这么做 / 走对的和走岔的 / 现在还剩什么 / 饭桌上怎么说 / 时间线。看重点是第三节——每一家的分岔，当年都只是一次取舍，回头看才叫分岔。

**事件篇**（93）跟模型篇同一套骨架：一次比赛、一个数据集、一个台阶，为什么是那一年。

**公司篇**（86–90）七节，跟模型篇同一套骨架，重点放在合约和治理：钱从哪来、分销给了谁、谁在关键投票里没有位置。模型是技术选择，公司是分配选择，后者更能解释一个人为什么会被换掉。

**人物篇**（76–77、84–85）五节：他是谁 / 他信什么 / 对在哪，错在哪 / 他为什么这么说 / 饭桌上怎么说。这一行里，人比参数更能解释选择：同样是看到那条曲线，有人去做产品，有人去做安全，有人去做世界模型。

**时间线**每条都带出处。年份、参数量、金额这类数字，能查到原文才写；查不到就不写，写在文里比写错强。

## 收录标准

一、**能一句话说完它赢在哪**。说不出，说明还没看懂，不写。

二、**带得出一条取舍**。当年那个选择，在当时是不是也说得通；如果它只是运气好，就不是家谱，是传说。

三、**数量能数清**。现在收到十五个模型与事件、五家公司、四个人。再多就成了公司名录，读者记不住；所以每加一个，都要能说清它赢在哪。

## 一条纪律

这一卷最容易写错，因为年份、参数、发布会细节全都有据可查，而人的记忆靠不住。所以：每个数字后面都有链接；两个来源打架时，把两个都写出来，不替谁圆；发现自己写错了，直接改，改动记在[更新日志](/updates)。

## 这一卷还缺什么

缺口是明码写出来的，免得读者以为没写的就是没有。

- **前史**。这一卷从 2012 年写起，2012 年之前那五十六年（达特茅斯会议、专家系统、两轮寒冬）一笔带过。没有前史，读者会以为 AI 是 2022 年突然出现的。
- **语音**。Whisper 之后，语音识别和合成已经不新鲜，但饭桌上提到「实时翻译耳机」时，这一卷接不住。
- **机器人**。Figure、宇树、V-JEPA 之后那条路线，现在只有卷一的一篇《具身智能》顶着。
- **图像与视频的两条支线**。DALL·E 与 Midjourney 走的是两条路；可灵、Veo 又各自成线，Sora 那一篇只写了 OpenAI 的视角。
- **中国这一侧的另外几家**。豆包与 Seed、Kimi、MiniMax 都还没进来。现在收的六家里，有四家是 2023 年就上台的，说服力在衰减。
- **欧洲与中东**。Mistral、xAI，一个是开源路线的欧洲样本，一个是「算力自建 + 话题驱动」的样本。
- **做工具的人**。黄仁勋进了英伟达那一篇，但整个「工具链」——框架、推理引擎、评测机构——还是一片空白。

排序按缺口大小，不按热度。前史和语音最缺，机器人和支线最容易过时，所以后者会先进卷五「当下」，等沉淀下来再收进这里。

家谱不是用来背的。它的用处是：下次有人说「某家突然就起来了」，你能说出它憋了几年，以及它在哪一年做过一个当时看起来很不划算的决定。
