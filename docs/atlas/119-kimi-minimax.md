# Kimi 与 MiniMax：入口之争的两种打法

## 这一族怎么长出来的

2023 年 3 月，月之暗面成立（[证券时报转 21 世纪经济报道，2024-05-24](https://stcn.com/article/detail/1213762.html)）。半年多以后，它推出了支持输入 20 万汉字的模型和搭载该模型的 Kimi Chat（[北京日报，2023-10-10](https://5g.dahe.cn/news/202310111315720)）。当时国内同行的上下文窗口还停留在几千到几万字，20 万汉字是个能被念出来的数字，也是一个能被写进标题的卖点。

同一年代，另一条路在别处起步。MiniMax 由原商汤副总裁闫俊杰在 2021 年 12 月创办，先做 AI 社交产品，再做工具（[财新，2024-12-25](https://m.caixin.com/m/2024-12-25/102271886.html)）。它没有去抢对话框的位置，而是去做能直接卖的东西：视频、语音、社交。

两家真正的分岔出现在 2024 年。Kimi 选择了买用户：按 AppGrowing 口径，2024 年 10 月单月投放 2.2 亿元，11 月又是 2 亿元（[财经天下，2024-12-07](https://tech.ifeng.com/c/8f7QEGiOs9Y)）。MiniMax 选择了卖产品：海螺 AI 上线 8 个月，全球网页端月均活跃用户接近 1000 万，三款产品年化收入 7000 万美元（[财新](https://m.caixin.com/m/2024-12-25/102271886.html)）。

到 2025 年，两家的模型又都走到了开源这一边。Kimi K2 发布并开源，上线一周后登顶开源模型榜（[北京日报，2025-07-24](https://xinwen.bjd.com.cn/content/s6882255ae4b0bd64e2e1616a.html)）；MiniMax M2 开源，明说是为 Agent 和代码做的，权重放在 HuggingFace 上（[MiniMax，2025-10-27](https://www.minimax.cn/blog/minimax-m2)）。

## 技术路线

两家都想占住入口，但入口的定义不一样。

**Kimi 把入口当广告位。** 长文本是钩子，投放是杠杆，产品是一个尽量不打扰人的对话框。用户来了之后，再想办法把「能读长文档」变成「每天都要用」。K2 之后，重心往 Agent 与编程挪：不是让人多聊两句，是让人把活交出去。

**MiniMax 把入口当橱窗。** 视频、语音、社交，每一样都能单独收费，也都能单独传播。它不需要用户记住公司名，只需要用户想生成一段视频时打开海螺。M 系列开源，是把模型当零件卖给开发者，顺便把 Agent 产品接上去。

一句话对照：一家把钱花在买用户上，一家把钱花在做产品上。买来的用户要留存才算数，做出来的产品要复购才算数。两条路都要过同一道关，只是账单长得不一样。

## 现在谁在用

**C 端付费用户。** Kimi 的订阅与 API，MiniMax 的订阅与广告。财新给出的年化收入口径是 7000 万美元，主要来自广告和订阅（[财新](https://m.caixin.com/m/2024-12-25/102271886.html)）。

**海外创作者。** 海螺 AI 的网页端月活接近 1000 万，这是它最实在的一块资产（[财新](https://m.caixin.com/m/2024-12-25/102271886.html)）。做视频的人不太在意模型叫什么，只在意出片快不快、像不像。

**开发者。** K2 与 M2 都放了权重，能自己部署，也能接进 Cline、VS Code 这类工具里（[MiniMax](https://www.minimax.cn/blog/minimax-m2)、[北京日报](https://xinwen.bjd.com.cn/content/s6882255ae4b0bd64e2e1616a.html)）。对开发者来说，开源意味着两件事：便宜，以及不怕你哪天涨价。

## 预期寿命

**还能当默认选择多久。** 这是估计值，不是数据。Kimi 这条「投放换用户」的路，估计还有 1–2 年的窗口，之后必须换挡成留存与付费。MiniMax 这条「多模态加海外订阅」的路更长一些，估计 3–5 年，但它站在视频生成的降价通道上，价格战会先咬到它。

**判断依据看四个方向。** 用户在搬家：投放一停，新增就掉，说明买的是流量不是习惯。价格在跌：API 单价和视频生成单价往下走，靠价差活着的产品先出局。生态在长：开源权重被多少下游真正采用，比 star 数实在。接口在废：当工具链默认只认某一种接口，闭源 API 的议价权就没了。

**过期的信号。** Kimi 这边，投放费用降下来而月活不降，是好事，说明留存立住了；反过来，投放回升而月活不动，就是买不动了。MiniMax 这边，海螺的月活被后来者反超，或者视频单价跌到接近免费而订阅没跟上，橱窗就空了。

真正的分界不在模型榜上，在账单上：谁的收入不是靠融资续着，谁就多一条命。
