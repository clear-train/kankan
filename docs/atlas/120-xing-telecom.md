# 星辰：运营商的大模型，先给自己用

## 这一族怎么长出来的

这一族原来叫 TeleChat，后来改叫 Xing。改名的动作本身有信息：它不再强调「电信语义」，而是把自己当成一个型号来经营。

2026 年 9 月 17 日，中电信人工智能科技发布 Xing4.0-29B-A4B。MoE 架构，总参数 29B，每个 token 激活 4B，官方称是国内首个基于国产算力和国产框架完成训练、面向复杂工程任务优化的百亿参数模型（[人民邮电报，2026-09-18](https://m.haiwainet.cn/middle/3541089/2026/0918/content_32984070_1.html)）。低比特量化之后显存占用大幅下降，消费级显卡能本地跑；权重放上了 GitHub、Hugging Face、Gitee、魔搭、魔乐。

两个月后，Xing4.1-Preview 出现在 Hugging Face：8,192 张昇腾 910C、MindSpore 训练框架，总参数 285B、每 token 激活 17B，原生 100 万 token 上下文，Apache 2.0 许可，技术报告挂在 arXiv 2611.22115（[Hugging Face，2026-11](https://huggingface.co/XingChen-AGI/Xing4.1-Preview)）。

从 29B 到 285B，两个月。这个间隔说明它不是在追一条通用曲线，而是在按自己的算力条件往上爬。

## 技术路线

三条，都带着「国产硬件优先」的痕迹。

一是架构为芯片让路。模型卡写得很直白：不照搬别人的架构再往昇腾上搬，而是按 910C 的长处做协同设计——它的矩阵算力强、向量算力紧，所以选了以矩阵乘为主的稀疏注意力（DeepSeek 的 DSA），而不是理论复杂度更好看、但对向量单元要求高的混合线性注意力。

二是注意力复用。MLA 压 KV，DSA 让长上下文只算该算的部分，原生 100 万 token 就是这么来的。这两个零件都来自 DeepSeek V3.2 那条公开路线——国产模型之间互相抄作业，是这一轮很真实的景象。

三是双形态权重。原生是 MindSpore 格式，同时提供转好的 PyTorch safetensors，能直接进 vLLM、SGLang。这一步是为了让「国产框架训练」不至于变成「只有国产框架能跑」。

## 现在谁在用

官方场景是三大类：网络与运维（告警、工单、排障）、客服与政企项目（合同、材料、问答）、以及面向开发者的 Agent 调用。模型卡里列了它测过的几个 Agent 外壳：Codex、OpenCode、Pi、Claude Code、WorkBuddy——这个细节挺诚实，说明它把自己定位成「被别的工具调用的那一层」。

商业上它跟百度不是同一门生意。这是我的判断，不是官方说法：运营商不需要靠 API 抢通用市场，它需要自家的网络、客服、政企项目里有东西可用，还需要一个「国产算力能跑大模型」的说法。**模型是它买算力的理由，不是它卖的东西。**

## 预期寿命

给两个数。

29B 那一档（Xing4.0-29B-A4B）：**12 到 18 个月**。理由是端侧和私有化这条线的换代节奏本来就快，而且 29B 这个尺寸是全行业最挤的区间，同价位替代品永远有。

285B 那一档（Xing4.1 系列）：**18 到 24 个月**，前提是昇腾的供给跟得上。如果算力被卡，寿命会被动拉长——不是因为它更好，是因为换不起。

过期信号：模型卡不再提「国产框架」而是默认、昇腾之外的芯片也进了训练集群、Xing 系列开始按季度发版而不是按半年。
